# Bahdanau Attention PV Point Forecast

An advanced machine learning-powered web application designed to forecast photovoltaic (PV) power generation using Numerical Weather Prediction (NWP) data and a custom ensemble deep learning model featuring **Bahdanau Attention**.

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://bahdanau-attention-point-forecast-eshctjukrprx9kj64g3bcw.streamlit.app/)

## ✨ Key Features
- **Interactive UI:** Built with Streamlit for seamless day selection and visual exploration.
- **Ensemble Predictions:** Combines multiple deep learning models to predict power generation curves with min/max confidence bounds.
- **Dynamic Plotting:** Interactive charts built with Plotly, showing average power forecasts alongside actual target energy values.
- **Detailed Insights:** View individual model predictions, historical meteo data, forecast horizons, and target variables across organized tabs.

## 🛠️ Tech Stack
- **Frontend / UI:** [Streamlit](https://streamlit.io/)
- **Visualizations:** [Plotly](https://plotly.com/)
- **Machine Learning / Deep Learning:** [PyTorch](https://pytorch.org/), [Scikit-learn](https://scikit-learn.org/)
- **Data Processing:** [Pandas](https://pandas.pydata.org/), [NumPy](https://numpy.org/)
- **Solar/Meteo Calculations:** [Pvlib](https://pvlib-python.readthedocs.io/)
